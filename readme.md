# Lean Coffee style voting

> [!NOTE]
> The running version of this project can be found at http://skipishere.github.io/vote

Ever wanted to run a Lean Coffee style vote but found when you're mostly remote that it's hard to count the thumbs on camera or some people would like to keep their camera off? This project is a simple web app that allows you to create a ballot with up, neutral, and down options.
Participants can vote by clicking the buttons or using the access keys `ALT + 1` for up, `ALT + 2` for neutral and `ALT + 3` for down. The votes are counted in real-time and displayed either to the host or to everyone, depending on the settings.

## Local development
Simply run `npm run dev` and you'll have an instance running on localhost
