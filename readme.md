# Remote voting

> [!NOTE]
> The running version of this project can be found at http://skipishere.github.io/vote

Ever wanted to run voting session but found when you're mostly remote that it's hard to count the votes on camera or some people would like to keep their camera off? This project is a simple web app that allows you to chose a voting system, share the link with your participants and let them vote remotely.

## Lean Coffee
Participants can vote by clicking the buttons or using the access keys `ALT + 1` for up, `ALT + 2` for neutral and `ALT + 3` for down. The votes are counted in real-time and displayed either to just the host or to everyone.

## Fist to Five
If you want to get a vote on how much people agree with a statement, you can use the fist to five voting system. Participants can vote by clicking the buttons with 0 being a fist (Block) all the way up to 5 (Champion). At the end of the voting session the votes are displayed with the names to show where the distribution of votes is.

## Local development
Simply run `npm run dev` and you'll have an instance running on localhost
